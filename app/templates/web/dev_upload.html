Upload Document

Calls POST /api/v1/upload/document (multipart form). The filename you send is joined into the server's storage path with no normalization and no extension allow-list, so ../ in the filename escapes the intended uploads/ folder entirely.

A native file picker never lets you type a path into a filename, so this page sends whatever is in the "Filename to send" box instead of the picked file's real name - exactly like editing the multipart body in Burp Suite would.
