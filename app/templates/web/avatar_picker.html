Choose an avatar

Pick one of the 5 built-in avatars below. Selecting one calls POST /api/v1/upload/avatar with {"url": ...} - the same endpoint any "set avatar from a URL" feature would use. This page does not print that URL anywhere on screen or in the page's HTML: each thumbnail is loaded with JavaScript and drawn from the image bytes directly, so the address it came from only shows up in your browser's DevTools → Network tab - the same place it would show up for any other image request.

Behind this picker, /api/v1/upload/avatar fetches whatever URL it is given, server-side, with no validation - see Chapter 16 (SSRF). This page only ever sends it one of the 5 preset URLs above; nothing here restricts what the endpoint itself will accept when called directly.
