XML Import (Legacy Partner)

Calls POST /api/v1/integrations/xml-import with a raw Content-Type: application/xml body - a legacy partner integration that still speaks XML instead of JSON. The server parses it with external entities enabled, so a <!DOCTYPE> that declares an external entity gets resolved before the <username>/<bio> fields are read back out - including entities that point at a file on the server's own disk.

The safe example is an ordinary profile update. The XXE example adds a <!DOCTYPE> that defines an entity reading file:///etc/passwd and uses that entity as the <username> value - the same thing a proxy like Burp Suite would let you do by hand-editing the request body.
