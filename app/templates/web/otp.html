One-time code (OTP)

Calls POST /api/v1/otp/request and POST /api/v1/otp/verify. This lab is self-contained - no real SMS is sent, so the endpoint hands the code straight back in its own response instead.

/api/v1/otp/request really does limit you to 3 requests per 60 seconds - try clicking "Request code" four times quickly to see the 429. This page has no way around that (it never sets custom request headers), but the limiter itself keys on a client-supplied X-Forwarded-For header - calling the endpoint directly and rotating that header on every request resets the limit each time. See Chapter 13 (Rate Limiting).
