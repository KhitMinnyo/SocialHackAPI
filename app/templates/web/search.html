Search

Calls GET /api/v1/users/search?q=... to search usernames and bios. One deliberate difference from every other page in this app: before the request ever leaves your browser, this page's own JavaScript (search.js) strips characters commonly used to break out of a SQL string (', --, /* */, ;). Try the "SQL injection attempt" example below - it will not cause an error here.

This filter only protects this page. It runs entirely in your browser, so it never reaches /api/v1/users/search itself - anyone who calls that endpoint directly (curl, Postman, or replaying/editing the request in Burp Suite) skips this page's JavaScript completely and can still inject. A safe-looking web app does not mean the API behind it is safe. See Chapter 20 (SQL Injection).
