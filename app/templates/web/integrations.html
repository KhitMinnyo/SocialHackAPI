Integrations

A click-through UI for the "partner API" endpoints in app/routes/integrations.py (OWASP API10:2023 - Unsafe Consumption of APIs). Same as everywhere else in SocialHack: these pages just call the existing /api/v1/integrations/* endpoints with fetch() - nothing here is new backend behavior.

Exchange Rate

Fetch a currency rate from a provider URL you supply, and see the raw response the app blindly trusts (GET /api/v1/integrations/exchange-rate).

Import Profile from Partner

Import profile fields from a partner URL you supply - including fields a real partner should never be able to set (POST /api/v1/integrations/import-profile).
