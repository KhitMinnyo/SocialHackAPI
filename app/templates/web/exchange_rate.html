Exchange Rate

Calls GET /api/v1/integrations/exchange-rate?provider=<url>. The app fetches whatever URL you give it and trusts the JSON rate field it gets back, with no domain allow-list and no sanity check on the value.

Prefilled with a local static JSON file so this works with no setup. Point it at your own JSON URL (e.g. one returning {"rate": 999999}) to see the missing validation for yourself.
